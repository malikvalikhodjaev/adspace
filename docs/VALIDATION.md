# Проверки Maydonlar

24 сентября 2026 года для серверной версии 0.2.27 локально пройдены `npm run typecheck`, `npm run test:calendar`, `npm run test:navigation` (14 проверок) и `npm run test:analytics`. Проверены в том числе границы времени Ташкента, статусы согласия владельца, вместимость календаря и построение маршрутов админки. Публичные `/`, `/partners`, `/admin` и `/devshow` отвечали HTTP 200; ответ `/admin` сам по себе не означает, что анонимному посетителю доступны административные действия. Этим прогоном не проверялись физический LED, платёжный провайдер или связь с CMS.

Интеграционный набор с отдельной тестовой БД запускается как `npm run test:server`; для него нужны FFmpeg и FFprobe. Порядок развёртывания и независимой проверки на сервере — в [SERVER-PILOT.md](SERVER-PILOT.md).

## Архив: AdSpace UZ 0.1.0-alpha.1

Этот отчёт относится только к прототипу Sites от 5 сентября 2026 года. Текущая серверная архитектура Maydonlar описана в [ADR-002](architecture/ADR-002-Maydonlar-server-MVP.md), а актуальные проверки запускаются командами из [SERVER-PILOT.md](SERVER-PILOT.md). Результаты ниже не следует выдавать за проверки текущей серверной версии.

Проверено 5 сентября 2026.

- TypeScript `--noEmit`: пройдено.
- Production build Vinext/Worker: пройдено.
- 19 проверок домена: даты, цена, повторное создание, коллизия календаря, двойная оплата, роли, два одобрения, отказ с причиной, новая версия креатива, фиксация цены, спор и сторно, блокировка, отмена, неверный файл, создание экрана, закрытые даты и защита существующей заявки.
- 11 проверок HTTP: отказ анонимному пользователю, чтение со входом, защита Origin, загрузка PNG, точное чтение байтов файла, защита файла от анонимного чтения, создание, идемпотентность, две одновременные оплаты, путь до завершения, повторное чтение сохранённого состояния.
- Первичный и обновлённый маршрут `/` отвечают HTTP 200; исходный файл и копия имеют одинаковый SHA-256 `30BAC768F322D4B7D417732BADDC155DA341F790B98C2426B8AE9A5CD7760D7D`.

Проверки API используют локальную тестовую идентичность официального Sites plugin. Они не доказывают работу платёжного провайдера, CMS или коммерческого эскроу. Внешние системы не подключены.

Автоматические проверки интерфейса в браузере и интервью с реальными пользователями не проводились. Камера и установка PWA требуют проверки на устройствах. WebMCP-поиск добавлен с feature detection, но поддерживаемый контекст для проверки его регистрации отсутствовал; проверенным он не объявляется.

Штатный type-aware lint первоначально не запустился из-за Windows cmd shim и символа `&` в каталоге проекта. Проверка TypeScript отдельно успешно выполнена. В стартовом наборе npm сообщил 14 уязвимостей зависимостей (6 moderate, 8 high); публичный коммерческий выпуск требует отдельного security-разбора, а не слепого `audit fix --force`.

ADR поставлен в редактируемом Markdown с последней найденной структурой Marosim v0.9. Исходные DOCX не менялись. Создание нового Word-файла не заявляется: доступный рендерер DOCX не нашёл bundled LibreOffice, поэтому непроверенный Word-экспорт не выдаётся за готовый артефакт.
