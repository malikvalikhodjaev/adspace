# Ручной LED-пульт: отдельный технический канал

Пульт: https://maydonlar.fom-analytics.uz/control. Ранее выданные ссылки плееров на старых поддоменах продолжают работать. Это дополнительный способ технической проверки удалённой смены файла, а не обязательный шаг размещения. Основной сценарий: календарь → согласие владельца → автоматическое расписание `/player/<screenId>`.

## Как пользоваться

1. Войти как оператор или администратор и открыть **LED-пульт**. Оператор видит свои экраны; администратор может использовать демонстрационный экран для проверки.
2. Выбрать экран и нажать **Подключить плеер**. Приватную ссылку открыть в браузере на телевизоре/втором компьютере. Включить полный экран. Ссылка — доступ только к воспроизведению этого экрана, не к управлению аккаунтом.
3. На управляющем устройстве выбрать PNG/JPG или MP4. Предпросмотр ещё не отправляет команду.
4. Нажать **Показать на экране**. Плеер сам получит новую версию, загрузит файл и сменит изображение без обновления страницы. Интервал опроса — 2 секунды плюс время загрузки/декодирования. Фоновая вкладка и режим сна устройства могут замедлить опрос.
5. В пульте дождаться **Плеер подтвердил показ** и совпадения отправленной/подтверждённой версии. **Очистить экран** удаляет материал из текущего показа, но не удаляет загруженный файл.

Выдавать новую ссылку для каждой картинки не нужно. **Выдать новую ссылку** отзывает прежний доступ; старые плееры перестанут получать команды. Если плеер закрыт, сервер хранит последнюю команду и применит её при подключении. Подтверждение означает реальное событие загрузки изображения или запуска видео в браузере, а не доказанный физический LED-показ.

## Видео и нагрузка

MP4/H.264 уже поддерживается: без звука, повторяется по кругу. Лимит — меньшая из величин 25 МБ и лимита выбранного экрана. Для тестового канала исходный файл не перекодируется на сервере; масштабирование с сохранением пропорций выполняет браузер. Неподдерживаемый кодек будет показан как ошибка, а не как успешный показ.

Это не видеотрансляция: файл скачивается при замене и сохраняется в кэше устройства, а повторы не требуют повторной загрузки видео. Очистка/вытеснение браузерного кэша приводит к новой загрузке. Отдельно идут небольшие периодические запросы команд и подтверждений. Например, файл 10 МБ на пяти новых плеерах — около 50 МБ передачи самого файла, без учёта служебного трафика. Основные параметры нагрузки — размер файлов, число экранов и частота замен, а не количество повторов.

## Границы и защита

- `/screen/...` — отдельный канал ручного управления. `/player/...` работает по календарному расписанию после согласия владельца каждого выбранного экрана, без отдельной проверки платформой. Пульт не изменяет размещения, договоры и условные финансы.
- Управлять может владелец-оператор или администратор. Выбор чужого файла, управление чужим экраном и чужие токены отклоняются.
- Команды имеют версии, ключ повторного запроса и журнал. Устаревшее подтверждение не может подтвердить новый файл; параллельное редактирование из устаревшей вкладки возвращает конфликт.
- Новый файл предварительно декодируется, пока виден старый. Плеер сообщает об ошибке загрузки; последняя успешная картинка остаётся до готовности замены или до истечения разрешения на показ.
- Если связь с сервером потеряна больше минуты, тестовый показ прекращается до получения нового разрешения. При восстановлении применяется последняя команда.
- Физический LED-контроллер/CMS не подключён. Для него по-прежнему нужно отдельно выяснить способ интеграции. Сейчас принимающая сторона — браузер с открытой страницей плеера.

## API для внешней команды

Управление: сессия авторизованного оператора/администратора, заголовок Origin адреса приложения. `GET /api/remote?screen=ID` возвращает текущую revision и подтверждение; `POST /api/assets` принимает файл. `POST /api/remote` с action `show`, screen, assetId, expectedRevision и новым UUID в key отправляет замену; action `clear` очищает показ. Это позволяет отправлять команду не только кнопкой пульта, но и из внешнего авторизованного клиента. Токен плеера не даёт права отправлять управляющие команды.

Проверки: `npm run typecheck`, `npm run build`, `npm run test:server`. Набор включает 27 интеграционных проверок. Браузерный сценарий: первая картинка → другая картинка → MP4 → картинка из UI → очистка, без перезагрузки принимающей страницы.
