## Проверено

- TypeScript и production-сборка.
- 21 интеграционная проверка локально и на Linux в отдельных временных базах: права, подмена роли, CSRF, чужие файлы/кампании, публикация экранов, реальный PNG/MP4 рендер с целевым FPS и обрезкой, календарь, повторные запросы, два одобрения, смена креатива, условия, плеер, отзыв токена, пауза/возобновление, спор/возврат и отзыв операторской роли.
- В браузере: мобильный каталог, вход оператора, отправка карточки на проверку, публичный каталог/карта; воспроизведение изображения 1920×1080 и повторные сигналы запуска в тестовом плеере.
- Опубликованный health endpoint, Marosim health endpoint и штатный защищённый ответ дашборда.

На самом сервере DNS нового поддомена обновлялся с задержкой. Проверка первого запуска использует публичный DNS-over-HTTPS, без изменения системного DNS. При штатном обновлении уже опубликованного AdSpace общий Cloudflare Tunnel не перезапускается.

## Доступ и следующие шаги

Приватный доступ владельца — `.local/adspace-pilot-access.txt` в основном локальном проекте. Пароль не хранится в Git и не публикуется. Участники регистрируют собственные аккаунты оператора/рекламодателя. Владелец назначает модератора через управление пользователями.

Первый тест: оператор добавляет реальный экран → модератор публикует → рекламодатель подготавливает креатив и принимает тестовые условия → модератор проверяет контент → оператор проверяет техпараметры → оператор открывает персональную ссылку плеера. Ссылку плеера нельзя публиковать: она содержит доступ к конкретному экрану.

Custdev и usability пока не проводились: готов [сценарий](PILOT-TESTS.md). [Бизнес-модель](BUSINESS-MODEL.md) — гипотезы для проверки, не подтверждённая экономика.

P1 (реальная физическая интеграция) отложен до уточнения LED-контроллера/CMS, прав доступа и требуемой телеметрии. One ID, утверждённого договора, реальных платежей, SMS, фискализации и доказанного наружного показа нет. Камеру надо дополнительно проверить на телефонах участников. Старый Site не удалён, его персональные данные не импортированы.
